GPU bytes = vertex and index buffers held for the terrain (mesh: 16 floats a vertex + 4-byte indices; splats: 16 bytes a voxel, its light included).
vertices run = vertex shader invocations per frame for the terrain in view; a splat is one, lit there once for its three faces.
build = on the meshing threads, never the frame; splats include baking each voxel's light (sky, bounce, lamps), unlit is without.
Splat chunks keep water as a small mesh; blocks beyond the detail rings are meshed either way.
Desktop JVM numbers; a low-end phone core is roughly 3-6x slower.
