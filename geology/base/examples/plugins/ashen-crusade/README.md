# The Ashen Crusade — a lore pack in data alone

An example of how far a plugin goes without code. It turns the built-in
world grimdark: ruined hives, a crusading order, a plague cult.

| It adds | Where |
| --- | --- |
| A damage type, five blocks and a region | `damageTypes`, `blocks`, `biomes` |
| Two factions that hate each other, with reputation ranks | `factions` |
| Five fighters with crowd roles (melee, ranged, swarmer, brute, support) | `enemies` |
| A warband that hunts as one: a cantor leading thralls and a brute | `enemyPacks` |
| Fortress bastions for the Crusade, war camps for the Choir | `settlements` |
| A stew and a foraging rule on top of the standard survival | `recipes`, `forage` |
| Soldiers an outpost can train and take into the field | `units` |
| How its worlds should be played: harsh, dangerous, raided | `rules` |
| A studio agent that writes new content in the Crusade's voice | `agents` |

Zip the two JSON files into `ashen-crusade.stratum` and open it in the
game, or drop the folder into the Plugins screen.
